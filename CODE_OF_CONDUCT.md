# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- **Be kind.** Disagree with ideas, not with people.
- **Be specific.** "This is wrong because X" beats "this is wrong".
- **No harassment.** Personal attacks, slurs, and unwelcome contact end your participation.
- **Assume good faith** until evidence proves otherwise.

## Scope

This applies to:
- GitHub issues, PRs, discussions, code comments
- Any community space where the project is discussed

## Reporting

If someone violates this, report to **conduct@humanswith.ai**. Reports are
confidential. We will respond within 72 hours.

## Enforcement

Maintainers may, depending on severity:
1. Issue a private warning.
2. Issue a public warning.
3. Temporarily ban from project spaces.
4. Permanently ban from project spaces.

Decisions are at maintainer discretion. They are appealable by emailing
conduct@humanswith.ai with the appeal in writing.
